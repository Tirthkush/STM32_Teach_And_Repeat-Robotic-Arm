# Drivers

This folder contains all device drivers used in the STM32 Teach-and-Repeat Robotic Arm project.

The drivers are divided into three categories:

- **CMSIS** – ARM Cortex-M core support files.
- **STM32F1xx_HAL_Driver** – STM32 Hardware Abstraction Layer (HAL) drivers generated by STM32CubeIDE.
- **Custom** – User-developed drivers for external peripherals used in this project.

The custom drivers provide hardware abstraction for devices connected over the I²C bus, allowing the main application to interact with them through simple APIs.
