# Images

This folder contains photographs and visual demonstrations of the STM32 Teach-and-Repeat Robotic Arm project.

## Contents

- **Full_Setup.jpg** – Complete hardware setup.
- **STM32_BluePill.jpg** – STM32F103C8T6 development board.
- **PCA9685.jpg** – 16-channel PWM servo driver module.
- **EEPROM.jpg** – External I²C EEPROM module.
- **Joystick.jpg** – Dual analog joystick controller.
- **Touch_Sensors.jpg** – Capacitive touch sensors used for Record and Playback.
- **Servo_Motors.jpg** – Servo motors used in the robotic arm.
- **Wiring.jpg** – Complete hardware wiring.
- **Demo.mp4** – Project demonstration.
