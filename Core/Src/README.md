# Src

This folder contains the application source files for the STM32 robotic arm project.

It includes the main program, peripheral initialization, and the application logic responsible for:

- Reading joystick inputs using ADC with DMA
- Controlling four servo motors through the PCA9685
- Recording servo positions to EEPROM
- Playing back recorded movements
- Processing touch sensor inputs
- UART debugging and status messages

The source files in this folder are generated by **STM32CubeIDE** with additional user-developed application code.
