# Inc

This folder contains the header files for the STM32 robotic arm project.

It includes function declarations, macros, peripheral definitions, and user-defined interfaces required by the application.

Typical files include:

- `main.h`
- Peripheral header files
- User-defined driver headers
- Application function declarations

These header files are generated by **STM32CubeIDE** with additional user-developed declarations where required.
