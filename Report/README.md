# Report

This folder contains the complete project report for the **STM32-Based Teach-and-Repeat Robotic Arm**.

The report documents the complete design, implementation, and testing of the project, covering both hardware and software aspects. It explains the overall system architecture, custom driver development, motion recording and playback algorithms, peripheral interfacing, and project outcomes.

## Contents

- Project Abstract
- Introduction
- Objectives
- Hardware Components
- Software Tools
- System Architecture
- Hardware Design
- Software Design
- Custom PCA9685 Driver
- Custom EEPROM Driver
- Motion Recording Algorithm
- Motion Playback Algorithm
- EEPROM Memory Organization
- Circuit Connections
- Testing & Results
- Challenges Faced
- Future Scope
- Conclusion
- References

This report serves as the primary technical documentation for the project and can be used to understand the design methodology, firmware architecture, and implementation details of the robotic arm.
